# 🏦 Sistema Bancário em Java

## 🚀 Projeto desenvolvido por Paulo Henrique

---

## ✨ Sobre o Projeto

Este é um **sistema bancário simulado em Java puro**, desenvolvido com foco em prática de lógica de programação, Programação Orientada a Objetos (POO) e estrutura de aplicações reais.

O sistema permite criar contas bancárias e realizar operações básicas como:

- 💰 Depósitos
- 💸 Saques
- 🔁 Transferências
- 📄 Listagem de contas

---

## 🧠 Objetivo

O objetivo deste projeto é simular o funcionamento básico de uma agência bancária, aplicando conceitos fundamentais de desenvolvimento backend em Java.

---

## ⚙️ Tecnologias Utilizadas

- ☕ Java (JDK 8+)
- 📦 ArrayList (estrutura de dados)
- 🧾 Scanner (entrada de dados via console)
- 🧮 Programação Orientada a Objetos (POO)

---

## 🧩 Estrutura do Projeto

Programa/
├── AgenciaBancaria.java → Controle principal do sistema
├── Conta.java → Lógica da conta bancária
├── Pessoa.java → Dados do cliente
Utilitarios/
├── Utils.java → Formatação de valores



---

## 🏦 Funcionalidades

### ➕ Criar Conta
Cria uma nova conta bancária associada a um cliente (nome, CPF e e-mail).

---

### 💰 Depósito
Permite adicionar saldo à conta informada.

---

### 💸 Saque
Permite retirada de valores, respeitando saldo disponível.

---

### 🔁 Transferência
Transfere valores entre contas de forma segura.

---

### 📄 Listagem de Contas
Exibe todas as contas cadastradas no sistema.
